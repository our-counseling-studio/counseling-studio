# 우리들의 상담 수첩 — 디자인 시험판

기존 core.js, store.js는 변경하지 않았습니다. 메뉴와 현황 표시만 app.js에 추가했습니다. 기존 입력 및 저장 이벤트는 유지했습니다.

## 배포 전 확인
- 포스터 앱과 다른 웹 출처(도메인)를 사용합니다. 같은 GitHub 계정의 다른 저장소 경로만으로는 출처가 분리되지 않습니다.
- 실제 상담 자료, 백업, 개인정보, 인증정보는 배포하거나 테스트에 사용하지 않습니다. 배포 파일은 이 압축의 프로그램 파일만 허용합니다.
- HTTPS에서 가상 데이터로 폴더 승인, 재실행, 저장·복원, 오프라인, Windows 재부팅, 업데이트 및 아이콘을 확인합니다.
- 이 앱은 파일 암호화 또는 사용자 인증을 제공하지 않습니다. 실제 상담 자료의 사용 전 기관 보관 정책, Windows 접근 권한, 백업 삭제 절차 등을 검토해야 합니다.
